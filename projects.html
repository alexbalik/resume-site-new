Tower of Hanoi Desktop Application

Python (NumPy)

This was my first personal programming project, and I used it to learn Python. For this, I created a rudimentary user interface in the Python IDLE editor that displayed a game board with simple keyboard characters. With the user interface as a guide, user could move pieces between three columns under puzzle constraints with moves recorded along the way. The goal was for the user to beat the game and look back at the list of moves to discover the winning algorithm. The next step would've been to make the game solve itself, but I stopped there (I ended up moving on to my next project!)
